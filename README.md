# BRAWL ARENA

A Brawlhalla-style 2D platform fighter built with pure HTML5 Canvas + JavaScript. No dependencies, no build step.

**Play:** open https://shadwomtech017-glitch.github.io/Brawl-arena/

## Modes
- **1 Player** — fight an AI bot
- **2 Players** — local versus

## Controls

| Action | Player 1 | Player 2 |
|---|---|---|
| Move | A / D | ← / → |
| Jump (×2) | W | ↑ |
| Fast-fall | S | ↓ |
| Light attack | J | , |
| Heavy attack | K | . |

## Rules
- Rack up damage % — the higher it is, the further you fly when hit.
- Knock opponents off the stage into the blast zones. 3 stocks each, last one standing wins.
- Dodge moves give brief invincibility.

## Run locally
Just open `index.html` in any modern browser, or serve the folder:
```bash
npx serve .
```
